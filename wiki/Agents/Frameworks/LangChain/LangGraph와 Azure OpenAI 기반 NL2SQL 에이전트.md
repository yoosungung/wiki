# LangGraph와 Azure OpenAI 기반 NL2SQL 에이전트

LangGraph와 Azure OpenAI를 기반으로 하는 자연어-SQL 쿼리 에이전트 프로젝트입니다.

### 주요 기능

*   **다중 데이터베이스 지원**: 사용자 질문을 적절한 데이터베이스로 라우팅합니다.
*   **의도 감지**: 사용자의 질문 의도를 파악합니다.
*   **다중 턴 대화**: 여러 차례의 대화를 통해 맥락을 파악하고 답변을 정교화합니다.
*   **SQL 유효성 검사**: 생성된 SQL 쿼리의 유효성을 검사합니다.
*   **데이터 시각화**: 쿼리 결과를 시각화하여 제공합니다.

### 지원 데이터베이스

*   PostgreSQL
*   Azure SQL
*   Cosmos DB 등

### 사용 방법

CLI 및 Chainlit 웹 UI를 통해 사용할 수 있습니다.
