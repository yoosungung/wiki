# Claude Code: 에이전틱 코딩 워크플로우 (Plan-Execute)

## 요약
Anthropic이 출시한 터미널 기반의 자율 코딩 에이전트 도구입니다. 개발자가 터미널에서 직접 대화하며 대규모 코드베이스를 분석하고, 리팩토링 및 새로운 기능을 구현할 수 있도록 돕습니다.

## 핵심 특징
- **Plan Mode & Execute Mode**: 복잡한 작업 시 먼저 계획을 세우고 사용자 승인을 받은 뒤 실행하는 정교한 워크플로우.
- **전체 프로젝트 맥락 파악**: 수백 개의 파일을 한꺼번에 분석하여 아키텍처 수준의 변경 사항 반영 가능.
- **도구 사용 최적화**: 파일 읽기, 쓰기, 쉘 명령어 실행 등 개발에 필요한 도구를 높은 정확도로 활용.
- **에이전트-네이티브**: 단순한 코드 완성을 넘어 프로젝트 매니저처럼 작업을 주도.

## 기존 지식과의 연결
- LLM-Agent: 개발자의 생산성을 극대화하는 '페어 프로그래머' 에이전트.
- AIOps: 인프라 코드(IaC) 관리나 DevOps 자동화에 즉시 투입 가능한 도구.
- Deep Agents: 장기 계획과 복합 도구 사용 능력을 갖춘 Agents 2.0의 대표 사례.
