# Microsoft Agent Framework

## From Devblog

Microsoft Agent Framework는 복잡한 다중 에이전트 AI 시스템의 생성, 배포 및 관리를 단순화하도록 설계된 오픈 소스 SDK 및 런타임입니다. Semantic Kernel의 엔터프라이즈급 기능과 AutoGen의 혁신적인 오케스트레이션 기능을 결합하여 AI 연구를 프로덕션 환경으로 전환하는 것을 용이하게 하는 것을 목표로 합니다. 이 프레임워크는 개방형 표준, 확장성 및 엔터프라이즈 준비 상태를 우선시하며 관찰 가능성, 보안 및 장기 내구성과 같은 기능을 제공합니다. LLM 기반 에이전트 오케스트레이션과 비즈니스 로직 기반 워크플로 오케스트레이션을 모두 지원하므로 개발자는 작업에 적합한 접근 방식을 선택할 수 있습니다.

## From GitHub

Microsoft Agent Framework는 .NET 및 Python을 모두 지원하는 AI 에이전트 및 다중 에이전트 워크플로를 구축, 오케스트레이션 및 배포하기 위한 포괄적인 다국어 프레임워크입니다. 그래프 기반 워크플로, 실험적 패키지(AF Labs), 대화형 개발자 UI(DevUI), 관찰 가능성을 위한 내장 OpenTelemetry 통합, 여러 LLM 공급자 지원과 같은 기능을 제공합니다. 이 프레임워크는 스트리밍, 체크포인트, human-in-the-loop 및 시간 이동과 같은 기능을 갖춘 간단한 채팅 에이전트부터 복잡한 다중 에이전트 시스템에 이르기까지 모든 것을 만드는 데 사용됩니다.
