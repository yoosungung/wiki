# Kotaemon

RAG 서비스 개발 중이라면 #kotaemon 를 꼭 참고하세요! 🤖 깃헙에서 24.4k🌟를 받은 완성도 높은 오픈소스 솔루션인데요, GraphRAG, 키워드/벡터 검색, 이미지 인식, 정보 출처 표시 등 기본적으로 rag에 기대하는 모든 기능을 지원합니다. 문서 기반 AI 서비스를 빠르게 프로토타이핑하고 싶다면 시도해 보는 것도 좋을 거예요. 개발하고자 하는 프로덕트의 좋은 baseline이 되어 줄 것 같네요. Docker 컨테이너와 REST API를 통해 OpenAI, Claude, Ollama 같은 다양한 LLM 플랫폼과 즉시 통합도 가능하답니다. - 주요 기능 요약 ✅ 하이브리드 RAG 파이프라인: full-text + vector 검색 + re-ranking으로 최고 정확도 보장 ✅ 멀티모달 QA 지원: 텍스트, 이미지, 표가 포함된 복잡한 문서도 완벽 처리 ✅ 고급 인용 시스템: PDF 뷰어에서 하이라이트와 함께 정확한 출처 즉시 확인 ✅ 멀티유저 웹 UI: 개인/공개 컬렉션으로 팀 협업 및 지식 공유 자동화 ✅ GraphRAG 통합: 복잡한 추론과 멀티홉 질문도 에이전트 기반으로 완벽 해결 100% 무료 오픈소스!
