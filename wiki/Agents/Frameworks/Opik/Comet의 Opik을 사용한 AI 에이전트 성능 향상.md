# Comet의 Opik을 사용한 AI 에이전트 성능 향상

Avi Chawla는 100% 오픈 소스 기술인 Comet의 Opik을 사용하여 AI 에이전트의 성능을 184% 향상시켰다고 공유했습니다. 그는 AI 엔지니어들이 수동 프롬프트 엔지니어링을 하지 않고도 에이전트 워크플로우에 가장 적합한 프롬프트를 자동으로 찾을 수 있는 방법을 설명합니다. 이 방법은 초기 프롬프트와 평가 데이터셋으로 시작하여 최적화 도구가 프롬프트를 반복적으로 개선하여 최적의 프롬프트를 자동으로 얻는 간단한 아이디어에 기반합니다. Opik은 100% 오픈 소스 LLM 평가 플랫폼으로, 추적, 평가 및 대시보드를 제공하며, 모든 것이 로컬 LLM을 사용하여 100% 로컬에서 실행될 수 있습니다. 댓글에서는 Opik의 GitHub 저장소 링크가 공유되었으며, 다른 사용자들은 Opik과 DSPy의 조합이 에이전트 성능 최적화에 효과적이라고 언급했습니다.
