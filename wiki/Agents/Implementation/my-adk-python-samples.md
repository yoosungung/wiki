# my-adk-python-samples

이 GitHub 저장소 `ksmin23/my-adk-python-samples`는 Google Agent Development Kit (ADK)으로 구축된 Python 에이전트 샘플 모음입니다. BigQuery 및 Vertex AI Search와 같은 Google Cloud 서비스와의 통합을 보여줍니다.

## 주요 에이전트

*   **GCP Release Notes Agent**: Google Cloud 릴리스 노트에 대한 질문에 답변하며, BigQuery 기반의 MCP Toolbox와 통합됩니다.
*   **Shop Search Agent**: Vertex AI Search for Retail을 사용하여 제품을 검색하는 쇼핑 도우미 에이전트입니다.
*   **Restaurant Finder Agent**: Google Maps Platform API를 활용하여 특정 요리나 재료를 기반으로 레스토랑을 찾는 대화형 AI 에이전트입니다.
*   **Shopper's Concierge Agent**: 하위 에이전트를 통해 리서치를 수행하여 더 관련성 높은 제품 추천을 제공하는 고급 쇼핑 도우미입니다.
*   **Agentic RAG (Retrieval-Augmented Generation)**: AlloyDB, BigQuery, Spanner와 같은 다양한 Google Cloud 데이터베이스 서비스를 벡터 검색에 사용하여 RAG 패턴을 구현하는 에이전트들입니다. 또한 Vertex AI RAG Engine 및 Vector Search와 통합된 샘플도 포함합니다.
*   **Agent Memory**: Redis를 사용하여 세션 상태 관리 및 장기 기억 서비스를 구현하는 방법을 보여주는 에이전트들입니다.
