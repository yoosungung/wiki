# IBM, CUGA(Configurable Generalist Agent) 프레임워크 공개

CUGA는 기업 자동화의 복잡한 요구사항을 충족하도록 설계된 강력하고 적응성 있는 에이전트 프레임워크입니다. 이는 IBM에서 축적된 모범 사례와 지식을 캡슐화하여 개발자가 복잡한 프롬프트 코딩 및 아키텍처 결정에서 벗어나게 합니다. CUGA는 복잡한 작업 실행, 다중 도구 활용, 구성 가능한 추론 모드를 제공하며, AppWorld 및 WebArena 벤치마크에서 뛰어난 성능을 보여주었습니다. 또한 Langflow와 원활하게 통합됩니다. IBM은 CUGA를 더욱 개선하고 에이전트 수명 주기 툴킷(ALTK)을 구축하여 에이전트 성능을 향상시킬 계획입니다.
