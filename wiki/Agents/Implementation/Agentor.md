# Agentor와 LiteMCP

**출처**: [원본 링크](https://www.linkedin.com/posts/kalyanksnlp_aiagents-aiengineers-mlengineers-activity-7398567826422349824-yW2H)

Kalyan KS가 AI 에이전트 시스템 구축을 위한 오픈 소스 프레임워크인 **Agentor**와 사용자 정의 MCP(Multi-Agent Communication Protocol) 서버를 구축하는 데 사용되는 **LiteMCP** 라이브러리를 소개합니다.

## Agentor
Agentor는 안전한 통합을 통해 에이전트 시스템을 쉽게 구축할 수 있도록 설계되었으며, AI 에이전트를 구축, 프로토타이핑 및 배포하는 가장 빠른 방법을 제공한다고 설명합니다.

## LiteMCP
LiteMCP는 표준 패턴을 사용하여 FastAPI와 직접 통합되는 네이티브 ASGI(Asynchronous Server Gateway Interface) 앱입니다. 이는 FastAPI의 기본 요소를 따르므로 개발 과정에서 우회적인 방법이 적고 개발 주기가 빠르다는 이점이 있습니다.
