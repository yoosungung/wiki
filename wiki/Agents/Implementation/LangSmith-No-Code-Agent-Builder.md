# LangSmith No-Code Agent Builder

LangChain은 개발자가 아닌 사용자도 에이전트를 구축할 수 있도록 LangSmith의 코드 없는 에이전트 빌더를 출시했습니다. 이 빌더는 메모리 기능과 안내형 프롬프트 생성을 포함하여 에이전트 구축의 진입 장벽을 낮춥니다.

LangSmith의 에이전트는 프롬프트(논리), 도구(외부 서비스와 상호작용), 트리거(백그라운드 이벤트에 반응), 서브에이전트(복잡성 관리)의 네 가지 핵심 구성 요소로 이루어져 있습니다.

이 도구는 이메일, 채팅, Salesforce 비서와 같은 내부 생산성 사용 사례에 유용하며, LangChain 및 LangGraph의 경험을 바탕으로 `deepagents` 패키지 위에 구축되었습니다.
