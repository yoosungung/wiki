이 문서는 Strands Agents와 Amazon S3 Vectors를 사용하여 RAG(Retrieval-Augmented Generation) 시스템을 구축하는 방법에 대한 간단한 가이드입니다. AWS Bedrock Knowledge Base 설정, 문서 임베딩을 위한 벡터 스토리지 생성, 정확한 정보 검색을 위한 메타데이터 필터링 구현 방법을 다룹니다. 또한 자연어를 사용하여 고객별 문서를 쿼리할 수 있는 지능형 에이전트를 구축하는 전체 프로세스를 안내하며, Python 코드 예제와 AWS 구성 단계를 포함합니다.
