# AI 에이전트를 위한 정밀한 차트 생성 자동화 기법

AI 에이전트가 데이터 가공 및 분석을 완수했음에도, 시각적 차트를 예쁘고 정확하게 출력하는 과정에서 빈번하게 JSON 파싱 에러나 장황한 코드 출력이 발생하는 문제가 상존해 왔습니다.

## 1. 기존 차트 생성 방식의 문제점
- 에이전트에게 전체 Vega-Lite 또는 ECharts 등의 원시 설정을 처음부터 끝까지 출력하도록 하면 불필요한 토큰 낭비가 발생하고, 출력 포맷이 어긋나서 개발자가 직접 수동 클린업 작업을 거쳐야만 차트 렌더링이 성공하는 등 연동 안정성이 떨어집니다.

## 2. 해결 방안: Chart.js 기반 컴팩트 시각화
- 차트 구성용 메타데이터(라벨, 데이터셋) 및 기초 설정만 최소한의 엄격한 스키마(JSON)로 추출합니다.
- 복잡한 렌더링 세부 사항이나 색상 테마, 마우스 호버 효과 등은 에이전트에게 지시하지 않고, 클라이언트 측 렌더러(Renderer) 라이브러리 설정으로 고정합니다.
- 이를 통해 토큰 소모량을 획기적으로 줄이고, 차트 포맷 유효성을 100% 가깝게 유지할 수 있습니다.
