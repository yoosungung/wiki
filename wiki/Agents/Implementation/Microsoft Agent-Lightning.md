# Microsoft Agent-Lightning

Microsoft의 Agent-lightning은 AI 에이전트를 훈련시키는 도구입니다. 이 도구는 코드 변경 없이 에이전트를 최적화할 수 있으며, LangChain, OpenAI Agent SDK, AutoGen 등 다양한 에이전트 프레임워크와 함께 작동합니다. 강화 학습, 자동 프롬프트 최적화, 지도 미세 조정과 같은 알고리즘을 지원합니다. Agent-lightning은 가벼운 아키텍처를 가지고 있으며, "LightningStore"를 통해 작업, 리소스 및 추적을 관리합니다. 문서, 예제 및 Discord 커뮤니티를 제공하며, Microsoft Research 프로젝트입니다.
