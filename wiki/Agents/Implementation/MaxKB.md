# MaxKB

MaxKB는 엔터프라이즈급 에이전트 구축을 위한 오픈소스 플랫폼입니다. 강력하고 사용하기 쉬운 이 플랫폼은 RAG(검색 증강 생성) 파이프라인을 통합하고, 강력한 워크플로우를 지원하며, 고급 MCP 도구 사용 기능을 제공합니다. MaxKB는 지능형 고객 서비스, 기업 내부 지식 기반, 학술 연구 및 교육과 같은 시나리오에 널리 적용됩니다.

## 주요 기능

*   **RAG 파이프라인**: 문서 업로드 및 온라인 문서 자동 크롤링을 지원하며, 자동 텍스트 분할 및 벡터화 기능을 통해 대규모 모델의 환각 현상을 효과적으로 줄여 우수한 스마트 Q&A 상호 작용 경험을 제공합니다.
*   **에이전트 워크플로우**: 강력한 워크플로우 엔진, 함수 라이브러리 및 MCP 도구 사용 기능을 갖추고 있어 복잡한 비즈니스 시나리오의 요구 사항을 충족하는 AI 프로세스 오케스트레이션을 가능하게 합니다.
*   **원활한 통합**: 제로 코딩으로 타사 비즈니스 시스템에 신속하게 통합할 수 있어 기존 시스템에 지능형 Q&A 기능을 빠르게 추가하여 사용자 만족도를 높입니다.
*   **모델 불가지론**: DeepSeek, Llama, Qwen 등과 같은 사설 모델과 OpenAI, Claude, Gemini 등과 같은 공개 모델을 포함한 다양한 대규모 모델을 지원합니다.
*   **멀티 모달**: 텍스트, 이미지, 오디오 및 비디오 입출력을 기본적으로 지원합니다.

## 기술 스택

*   프론트엔드: Vue.js
*   백엔드: Python / Django
*   LLM 프레임워크: LangChain
*   데이터베이스: PostgreSQL + pgvector
