`langchain-ai/deepagents` GitHub 리포지토리는 `deepagents`라는 Python 패키지를 소개합니다. 이 패키지는 계획 도구, 하위 에이전트, 모의 파일 시스템 및 상세한 프롬프팅을 통합하여 복잡한 작업을 처리할 수 있는 "Deep Agents"를 생성하도록 설계되었습니다. LangGraph를 기반으로 구축되고 Claude Code에서 영감을 받은 이 패키지는 사용자 지정 하위 에이전트, 모델 사용자 지정, 미들웨어 및 도구 실행에 대한 인간 참여 승인을 허용합니다.
