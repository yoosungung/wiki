Airweave는 AI 에이전트를 위한 오픈소스 컨텍스트 검색 계층입니다.

## 요약
Airweave는 다양한 앱과 데이터베이스에 연결하여 해당 콘텐츠를 검색 가능한 지식 기반으로 변환하고 REST API 또는 MCP를 통해 에이전트를 위한 표준화된 인터페이스를 제공합니다. 인증, 추출, 임베딩 및 서빙을 처리합니다. 이 프로젝트는 완전한 오픈소스이며 자체 호스팅하거나 관리형 서비스로 사용할 수 있습니다. Slack, Notion, GitHub 및 다양한 데이터베이스를 포함한 30개 이상의 통합을 지원합니다.
