# Open Notebook

Open Notebook은 Google의 Notebook LM에 대한 개인 정보 보호 중심의 오픈 소스 대안으로, 더 많은 유연성과 기능을 제공합니다. 사용자는 데이터를 제어하고, 16개 이상의 AI 모델 중에서 선택하고, 다중 모드 콘텐츠(PDF, 비디오, 오디오, 웹 페이지)를 구성하고, 다중 화자 팟캐스트를 생성하고, 지능형 검색을 수행할 수 있습니다. 이 프로젝트는 Python, Next.js, React, SurrealDB 및 LangChain으로 구축되었으며 쉬운 배포를 위해 Docker 이미지를 제공합니다.
