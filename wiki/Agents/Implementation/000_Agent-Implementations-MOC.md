# 🛠 AI 에이전트 구현 도구 및 플랫폼 MOC

다양한 목적으로 개발된 최신 AI 에이전트 프레임워크와 구현 도구들을 정리한 인덱스입니다.

## 1. 범용 에이전트 프레임워크 및 빌더
- [[wiki/Agents/Implementation/Agent-Lightning]]: 코드 변경 없이 다양한 프레임워크(LangChain, AutoGen 등)의 에이전트를 최적화하고 훈련하는 도구.
- [[wiki/Agents/Implementation/Agentor]]: 안전한 통합과 빠른 배포를 지원하는 오픈 소스 에이전트 구축 프레임워크 (LiteMCP 포함).
- [[wiki/Agents/Implementation/IBM_CUGA]]: 기업 자동화의 복잡한 요구사항을 충족하는 IBM의 구성 가능한 범용 에이전트 프레임워크.
- [[wiki/Agents/Implementation/LangSmith-No-Code-Agent-Builder]]: 개발자가 아닌 사용자도 에이전트를 구축할 수 있는 LangSmith 기반 노코드 빌더.
- [[wiki/Agents/Implementation/open-agent-builder]]: 오픈 소스 기반의 에이전트 빌더 환경.
- [[wiki/Agents/Implementation/MaxKB]]: RAG 파이프라인과 MCP 도구 사용을 지원하는 엔터프라이즈급 오픈 소스 에이전트 플랫폼.
- [[wiki/Agents/Implementation/프로덕션-AI-에이전트-아키텍처-7대-계층]]: 프롬프트를 넘어 신뢰성 있는 서비스를 구축하기 위한 7대 시스템 레이어 설계 가이드.

## 2. 자율 및 자기 진화형 에이전트
- [[wiki/Agents/Implementation/Agent0]]: 제로 데이터로부터 스스로 개선하고 진화하는 자율 에이전트 프레임워크 (Agent0-VL 포함).
- [[wiki/Agents/Implementation/Manus_1.5_release]]: 속도와 신뢰성이 크게 향상된 범용 작업 수행 에이전트 (웹 앱 개발 지원).
- [[wiki/Agents/Implementation/Self-Evolving-Agents-Self-Correction]]: 자가 진화 및 수정을 지원하는 메커니즘을 갖춘 에이전트.
- [[wiki/Agents/Implementation/Model-Native-Agentic-AI]]: 계획, 도구 사용, 메모리가 모델 내에 내재화되는 차세대 패러다임.

## 3. 특정 도메인 및 기능별 에이전트
- [[wiki/Agents/Implementation/Computer Use Agents]]: GUI(그래픽 사용자 인터페이스) 상에서 사람처럼 마우스와 키보드를 조작하는 에이전트.
- [[wiki/Agents/Implementation/DS-STAR) A State-of-the-Art Versatile Data Science Agent]]: 통계 분석, 시각화 등 데이터 과학 작업을 자동화하는 구글 개발 에이전트.
- [[wiki/Agents/Implementation/Event-Deep-Research]]: 역사적 인물의 삶을 연구하고 구조화된 타임라인을 추출하는 리서치 전문 에이전트.
- [[wiki/Agents/Implementation/Skyvern]]: 브라우저 기반의 복잡한 워크플로우를 자동화하는 에이전트.
- [[wiki/Agents/Implementation/building-agentic-payments-with-langchain-and-privy]]: 에이전트가 안전하게 결제 및 자산 이동을 수행할 수 있게 하는 에이전트 결제 솔루션.
- [[wiki/Agents/Implementation/Enterprise-Voice-AI-System]]: 모든 대화 내용을 구조화하여 RAG처럼 쿼리할 수 있는 음성 AI 시스템.

## 4. 인프라 및 컨텍스트 관리
- [[wiki/Agents/Implementation/AI OS]]: 수천 개의 에이전트가 활동하는 시대를 위한 데이터, 컴퓨팅, 정책 연결 기본 계층.
- [[wiki/Agents/Implementation/Airweave]]: 다양한 앱의 데이터를 검색 가능한 지식 기반으로 변환하는 컨텍스트 검색 계층.
- [[wiki/Agents/Implementation/Supermemory-Architecture-and-MCP]]: Cloudflare 기반의 에이전트 네이티브 영구 메모리 레이어 및 MCP 서버.
- [[wiki/Agents/Implementation/Deep-Agents-Sandbox]]: 에이전트의 안전한 코드 실행을 위한 격리된 샌드박스 환경.
- [[wiki/Agents/Implementation/LiteLLM Gateway - Vertex AI Agent Engine 지원]]: Vertex AI 에이전트를 OpenAI 호환 인터페이스로 표준화하여 관리.
- [[wiki/Agents/Implementation/my-adk-python-samples]]: Google ADK를 활용한 다양한 클라우드 서비스 통합 샘플.
- [[wiki/Agents/Implementation/FDE-대비-AI-엔지니어-및-객체-중심-에이전트-거버넌스]]: FDE 아키텍처의 한계와 AI 엔지니어링 내재화, 객체 중심 에이전트 거버넌스 기법 분석.
