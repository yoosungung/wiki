# Programmatic Tool Calling Agent

LangChain 커뮤니티에서 "Programmatic Tool Calling" 에이전트를 오픈 소스로 공개했습니다. 이 에이전트는 LangChain DeepAgent를 기반으로 구축되었으며, 샌드박스에서 코드를 실행하여 데이터 집약적인 작업에서 토큰 사용량을 85-98%까지 줄일 수 있습니다. MCP 도구를 Python으로 변환하며, LangGraph/LangSmith와 함께 프로덕션 환경에 바로 적용할 수 있습니다. Sandra Hinthorn은 이 에이전트가 AI 에이전트의 가능성을 확장하고 복잡하고 데이터가 많은 작업을 효율적으로 처리하는 데 기여할 것이라고 언급했습니다.
