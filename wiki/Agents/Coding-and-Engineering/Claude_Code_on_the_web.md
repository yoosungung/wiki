# Claude Code on the web

Anthropic이 웹에서 Claude Code를 출시했다고 발표했습니다. 이는 브라우저에서 직접 코딩 작업을 위임할 수 있는 새로운 방법입니다. 현재 연구 미리보기 베타 버전으로 제공되며, Anthropic이 관리하는 클라우드 인프라에서 여러 코딩 작업을 Claude에 할당할 수 있습니다. 이를 통해 버그 백로그 처리, 일상적인 수정 또는 병렬 개발 작업에 적합합니다. Claude Code on the web은 터미널을 열지 않고도 코딩 세션을 시작할 수 있게 하며, GitHub 리포지토리를 연결하고 필요한 것을 설명하면 Claude가 구현을 처리합니다. 각 세션은 격리된 환경에서 실시간 진행 상황 추적과 함께 실행되며, 작업 중에도 Claude를 조정할 수 있습니다. 또한, 모바일에서도 Claude Code를 사용할 수 있습니다. 모든 Claude Code 작업은 네트워크 및 파일 시스템 제한이 있는 격리된 샌드박스 환경에서 실행되어 보안을 강화합니다.
