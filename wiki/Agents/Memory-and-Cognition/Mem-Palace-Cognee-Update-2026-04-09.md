# Mem-Palace 및 Cognee 기반 에이전트 메모리 (2026-04-09)

## 요약
에이전트 메모리 분야는 단순 벡터 검색을 넘어 '기억의 궁전'과 같은 구조화된 아키텍처와 그래프 기반의 관계 추론 시스템으로 빠르게 진화하고 있습니다.

## 주요 내용
- **Mem-Palace:** '기억의 궁전' 기법을 가상화하여 적용한 오픈소스 도구로, LongMemEval에서 96.6%의 압도적인 성능을 기록했습니다. AAAK 압축 기술로 토큰 사용량을 획기적으로 줄였습니다.
- **Cognee 그래프 메모리:** 에이전트가 복잡한 관계를 추론할 수 있도록 돕는 그래프 기반 메모리 레이어를 제공하며, 최근 'Custom Graph Models' 기능을 강화했습니다.
- **StixDB:** 사용되지 않는 기억을 자동으로 감쇠시키고 유사한 기억을 병합하는 자율형 메모리 데이터베이스가 등장했습니다.
