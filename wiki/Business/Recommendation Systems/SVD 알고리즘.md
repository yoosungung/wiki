정의

SVD(특이값 분해, Singular Value Decomposition)는 행렬 분해 기법 중 하나로, 추천 시스템에서 많이 사용되는 방법입니다. SVD는 사용자-아이템 평점 행렬을 세 개의 행렬로 분해하여 잠재 요인을 추출함으로써 추천 작업을 수행합니다.

원리

SVD는 다음과 같이 ( m \times n ) 차원의 사용자-아이템 평점 행렬 ( A )를 세 개의 행렬로 분해합니다:
 A = U \Sigma V^T 

	•	( U ) : ( m \times k ) 차원의 직교 행렬로, 사용자 잠재 요인을 나타냅니다.
	•	( \Sigma ) : ( k \times k ) 차원의 대각 행렬로, 특이값(비중)을 나타냅니다.
	•	 V^T  :  k \times n  차원의 직교 행렬로, 아이템 잠재 요인을 나타냅니다.

적용 방법

	1.	데이터 준비: 사용자-아이템 평점 행렬을 준비합니다. 이 행렬은 사용자들이 아이템에 대해 평가한 점수로 구성됩니다.
	2.	행렬 분해: SVD를 사용하여 평점 행렬을 세 개의 행렬로 분해합니다.
	3.	잠재 요인 사용: 분해된 행렬에서 사용자와 아이템의 잠재 요인을 추출합니다.
	4.	평점 예측: 추출된 잠재 요인을 사용하여 사용자와 아이템 간의 평점을 예측합니다.

**장점**

• 	**차원 축소**: SVD는 높은 차원의 데이터에서 중요한 정보를 추출하여 차원을 축소할 수 있습니다.
• 	**일반화 능력**: 잠재 요인을 사용하여 새로운 사용자나 아이템에 대해서도 평점을 예측할 수 있습니다.

**단점**

• 	**계산 복잡도**: 큰 행렬을 분해하는 과정이 계산적으로 복잡할 수 있습니다.
• 	**희소 데이터**: 사용자-아이템 행렬이 희소할 경우, 성능이 떨어질 수 있습니다.

SVD 알고리즘은 추천 시스템에서 많이 사용되는 강력한 기법으로, 사용자와 아이템 간의 잠재 요인을 효과적으로 학습하여 높은 정확도의 추천을 제공합니다.
