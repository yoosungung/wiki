**1. 개요**
• 개인화된 추천 시스템, 그룹 추천 시스템, 지식 기반 추천 시스템, 평가 메트릭스 및 공정성 문제.

**2. [[wiki/Business/Recommendation Systems/개인화된 추천 시스템]]**
• **협업 필터링 기반**: 사용자의 과거 행동과 유사한 다른 사용자의 행동을 바탕으로 추천. 메모리 기반과 모델 기반으로 구분.
• **콘텐츠 기반**: 아이템의 속성을 바탕으로 사용자의 선호도를 예측. 텍스트, 이미지 등의 다중 모달 데이터 사용.
• **지식 기반**: 사용자와 아이템 간의 도메인 지식을 활용하여 추천. 초기 사용자가 많지 않을 때 유용.

**3. [[wiki/Business/Recommendation Systems/그룹 추천 시스템]]**
• **메모리 기반 접근법**: 그룹 구성원의 개별 선호도를 집계하여 추천.
• **모델 기반 접근법**: 기계 학습을 통해 그룹의 종합적인 대표를 학습하여 추천.

**4. 하이브리드 추천 시스템**
• **다중 소스 데이터 통합**: 다양한 데이터 소스를 효과적으로 통합하여 더 정확한 실시간 추천을 제공. 예를 들어, 콘텐츠 및 협업 필터링, 컨텍스트 정보를 통합한 시스템.

**5. 문제점 및 도전 과제**
• **강건성**: 공격에 견디고 성능을 유지하는 능력. 예를 들어, 적대적 공격에 대응하기 위한 방어 모델.
• **데이터 편향**: 훈련 데이터의 편향으로 인해 발생하는 문제. 인기도 편향, 선택 편향, 노출 편향 등이 포함.
• **공정성**: 추천 결과의 공정성 확보. 예를 들어, 사용자 또는 아이템 기반 공정성 문제 해결.

**6. 최신 동향**
• **딥 러닝 및 지식 그래프**: 딥 러닝과 지식 그래프를 활용하여 더 정교한 추천 모델 개발. 예를 들어, 그래프 신경망(GNN), 자율 학습 모델 등이 포함.
