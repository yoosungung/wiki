# OpenWiki Prompt v0.3 Upgrade

OpenWiki v0.3에서 프롬프트가 대대적으로 개편되어 보다 상세하고 정확한 위키 생성이 가능해졌습니다.

## 평가 결과 (DeepSWE 벤치마크 기준)
*   **성공률 개선**: 28.57% 증가 (35% → 45%, n=2 기준)
*   **토큰 사용량**: 14% 감소
*   **툴 호출 수**: 성공한 태스크당 26% 감소
*   위키에 포함되는 데이터 양이 시각적으로 확인될 정도로 크게 증가함.

## 비용 및 설치
*   **설치 명령어**: `npm install -g openwiki@0.3.0`
*   초기 위키 생성 시 소모되는 토큰이 기존 2~3M에서 10~15M 수준으로 증가했습니다.
*   하지만 Luna 모델에서 실행할 경우, 위키 초기화 비용은 여전히 1달러 미만입니다. (250만 줄 이상의 LangSmith 메인 모노레포를 처리할 때도 최대 7달러 수준 소요)
