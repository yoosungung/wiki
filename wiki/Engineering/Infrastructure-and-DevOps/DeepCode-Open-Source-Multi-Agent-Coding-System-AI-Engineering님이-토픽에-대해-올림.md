# DeepCode Open-Source Multi-Agent Coding System | AI Engineering님이 토픽에 대해 올림

Generate production-ready code from a paper, a description, or a URL automatically! Most coding agents take one type of input and run with it. DeepCode is an open-source multi-agent coding system from HKUDS that handles three completely different starting points and produces production-ready code from all of them. Feed it a research paper and it reads the methodology, mines reference implementations, plans the architecture, generates the code, and tests it before handing it back. Feed it a plain text description and it builds a fully functional frontend or backend application. Feed it a URL and it fetches the content, extracts the requirements, and generates the implementation. The same multi-agent pipeline runs underneath all three modes: • A Planner that decomposes the input into a structured implementation roadmap • A Reference Mining agent that discovers relevant repositories and code patterns • A Code Generation agent that synthesizes everything into working, tested code • An Orchestrator that coordinates all agents and adapts the workflow based on input complexity Three modes ship out of the box: • Paper2Code: reproduce any research paper's algorithm as production-ready code • Text2Web: generate fully functional frontend applications from a plain text description • Text2Backend: generate scalable backend code from simple requirements CLI and web UI available with one command. Docker support for zero-setup deployment. Works with OpenAI, Anthropic, Gemini, OpenRouter, and any OpenAI-compatible endpoint.
