# 텐센트 오픈소스 RAG 프레임워크 요약

하예진 강님의 LinkedIn 게시물에 따르면, 텐센트가 놀랍게도 올인원 RAG(Retrieval-Augmented Generation) 프레임워크를 오픈소스로 공개했습니다. 이 프레임워크는 ReACT 패턴을 기반으로 개발되어 지식베이스 검색, 웹 검색, 그리고 MCP(Multi-Component Pipeline) 도구를 자동으로 조합하여 사용자 질의에 대한 종합적인 답변을 생성합니다.

예를 들어, "우리 회사 정책과 경쟁사를 비교해줘"와 같은 복잡한 요청이 들어오면, 이 프레임워크는 내부 문서와 웹 검색을 동시에 수행하여 비교표까지 도출해낼 수 있는 기능을 갖추고 있습니다. 게시물 작성자는 이러한 기능이 상용 서비스로 제공될 경우 월 수백만 원에 달할 것이라고 언급하며, MIT 라이선스로 완전 오픈소스라는 점에 큰 놀라움을 표했습니다. 설치 또한 Docker Compose 명령 한 줄로 간편하게 완료할 수 있어 실무자들에게 매우 유용할 것으로 보입니다.

**주요 기능은 다음과 같습니다:**

*   **ReACT Agent 모드:** 지식베이스 검색, MCP 도구, 웹 검색을 자동 조합하여 종합적인 리포트를 생성합니다.
*   **하이브리드 검색:** BM25, Dense Retrieval, GraphRAG 기술을 결합하여 검색 정확도를 높입니다.
*   **멀티 지식베이스:** FAQ/문서 타입, 폴더/URL 임포트, 태그 관리, 크로스 검색 등을 지원하여 다양한 형태의 지식 관리가 가능합니다.
*   **MCP 도구 통합:** uvx/npx 런처를 통해 외부 서비스를 확장할 수 있습니다.
*   **웹 검색 내장:** DuckDuckGo가 기본으로 제공되며, 커스텀 검색 엔진으로 확장할 수 있습니다.
*   **Web UI + REST API:** 직관적인 대시보드와 표준 API를 동시에 제공하여 사용 편의성과 개발 유연성을 확보했습니다.

이 프레임워크는 기업 내부 문서 검색, 고객 지원 자동화, 연구 자료 분석 등 RAG 기술이 필요한 모든 분야에 즉시 적용 가능하다고 강조됩니다.
