- **Q3 LLM 에이전트 및 강화학습 동향**: 24개 연구 동향 정리, 장기 에이전트 컨텍스트 상태 관리, 에이전틱 RL을 위한 Rollout 미세 기여도 학습법
- **Active Inference 기반 컨텍스트 획득**: cs.AI arXiv 논문 "Active Inference as Context Acquisition" (arXiv:2608.19202) 분석, OQA 및 기대 자유 에너지 최소화 수식화
- **LLMRouter 쿼리 라우팅**: 오픈소스 다중 LLM 라우터 아키텍처 및 matrix factorization 기반 기법 비교, 새로운 모델 추가에 따른 Cold-Start 한계점 및 해결책
- **Claude Code 설정 및 에이전트 실무**: Anthropic 엔지니어 실전 관점의 실행 루프, 코드베이스 전체 스캔(Scan) 스펙, MCP 외부 데이터 연동 점진적 빌드 패턴
- **Claude Academy**: 공식 강의 코스(Claude.ai, Co-work, Code) 개요 및 프롬프트 최적화 리소스
- **NVIDIA SkillSpector**: 에이전트 스킬 정적/LLM 시맨틱 보안 취약점 스캐너 성능 지표(Precision 87%) 및 4.2만 개 스킬 취약점 통계(26.1% 취약, 5.2% 악성)
- **Inference-Time Recirculation**: 추론 시점 순환(Recurrence) 구조를 활용한 Perplexity 개선 및 동적 신뢰 상태 추적 (arXiv:2608.17981)
- **Colibrì CPU MoE 추론 엔진**: 메모리 계층(VRAM, RAM, NVMe) 배치를 통해 로컬 하드웨어에서 2.8T 모델을 구동하는 Single Tiered 아키텍처 및 dynamic prefetch
- **AgentENV 고속 샌드박스**: Kimi K3 에이전틱 RL 학습을 위한 Firecracker microVM 기반 고속 격리 플랫폼 (50ms 부팅, CoW Fork)
- **Pipecat 멀티모달 프레임워크**: 실시간 음성/비디오 스트리밍 대화형 에이전트 개발 및 분산형 MAS Shared Bus 오케스트레이션 기능
