# Transformer 모델의 구조와 작동 원리 - Part 2 - 아키텍처와 구현

### 2. Transformer 아키텍처 이해

- **"[Attention Is All You Need](https://arxiv.org/pdf/1706.03762.pdf)"** 논문 읽기: Transformer 모델을 처음 소개한 논문으로, 이 모델의 구조와 작동 원리에 대한 깊은 이해를 제공합니다.
- **Transformer 구조 분석**: Self-Attention 메커니즘, Positional Encoding, Multi-Head Attention, Feed Forward Neural Networks, Layer Normalization 등 Transformer 모델의 주요 구성 요소를 학습합니다.
- 학습 리소스 : [YouTube](https://youtu.be/AA621UofTUA)

### 3. 프로그래밍 실습

- **PyTorch나 TensorFlow를 사용한 구현**: 직접 코드를 작성하면서 Transformer 모델을 구현해봅니다. 이 과정에서 모델의 내부 작동 원리를 실제로 경험할 수 있습니다.
- **오픈소스 프로젝트 분석**: GitHub 등에서 접근 가능한 Transformer 모델의 오픈소스 구현을 분석하여 다른 개발자들이 어떻게 문제를 해결했는지 학습합니다.
