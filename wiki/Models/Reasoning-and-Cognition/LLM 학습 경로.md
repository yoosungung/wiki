LLM(Large Language Model) 엔지니어가 되기 위해서는 여러 기술적 지식과 실력을 갖춰야 합니다. Fine-Tuning 같은 고급 기술을 다룰 수 있게 되기 위한 학습 경로는 다음과 같은 순서로 진행될 수 있습니다:

### 1. 프로그래밍 기초

- **언어 선택**: Python은 데이터 과학 및 머신 러닝 분야에서 가장 널리 사용되는 언어 중 하나입니다.
- **프로그래밍 기본 개념**: 변수, 반복문, 조건문, 함수 등 기본적인 프로그래밍 개념을 익힙니다.

### 2. 데이터 과학 및 기초 통계

- **데이터 처리**: Pandas와 같은 라이브러리를 사용하여 데이터 처리 및 분석 기초를 배웁니다.
- **시각화**: Matplotlib, Seaborn과 같은 도구를 사용하여 데이터를 시각화하는 방법을 배웁니다.
- **기초 통계**: 평균, 중앙값, 표준편차, 확률 등 기초적인 통계 개념을 이해합니다.

### 3. 기계 학습

- **기계 학습 이론**: 지도 학습, 비지도 학습, 강화 학습 등의 기본 개념과 알고리즘을 배웁니다.
- **머신 러닝 프로젝트**: 실제 데이터셋을 사용한 머신 러닝 프로젝트를 수행하여 이론을 실습으로 연결합니다.

### 4. 딥 러닝

- **인공 신경망 기초**: 퍼셉트론부터 시작하여 다층 퍼셉트론(MLP), 합성곱 신경망(CNN), 순환 신경망(RNN)까지의 개념을 배웁니다.
- **딥 러닝 프레임워크**: TensorFlow, PyTorch 등 주요 딥 러닝 프레임워크를 사용하는 방법을 배웁니다.

### 5. 자연어 처리(NLP)

- **텍스트 처리**: 텍스트 전처리, 토큰화, 벡터화, 임베딩과 같은 기초적인 NLP 기술을 배웁니다.
- **NLP 모델**: RNN, LSTM, Transformer 모델 등을 사용한 자연어 처리의 고급 개념을 배웁니다.

### 6. 대규모 언어 모델(Large Language Models)

- **Transformer 아키텍처**: Transformer 모델의 구조와 작동 원리를 깊이 이해합니다.
- **Pre-training과 [[wiki/Models/SFT/Fine-Tuning]]: 대규모 언어 모델의 사전 훈련과 파인 튜닝 방법론을 배웁니다.
- **모델 최적화와 배포**: 모델의 성능 최적화([[wiki/Models/SFT/Optimizer]], [[wiki/Models/SFT/Booster]]) 및 실제 서비스에 모델을 배포하는 방법을 배웁니다.
- 리소스 : [vLLM](https://docs.vllm.ai/en/latest/), [[wiki/Models/Optimization-and-Serving/oLLM_Lightweight_LLM_Inference_Library]]

### 7. 실제 프로젝트 경험

- **프로젝트 수행**: 실제 문제를 해결하기 위한 프로젝트를 진행합니다. 공개 데이터셋 또는 자체 데이터를 사용하여 프로젝트를 기획하고, 모델을 훈련시키고, 결과를 평가합니다.
- **포트폴리오 구축**: 수행한 프로젝트를 문서화하여 포트폴리오를 만듭니다. 이는 잠재 고용주나 연구 기관에 당신의 역량을 보여줄 수 있는 중요한 자료가 됩니다.

이러한 경로를 따라 학습하면 LLM 엔지니어로서 필요한 다양한 기술과 지식을 습득할 수 있으며, Fine-Tuning을 포함한 고급 기술을 효과적으로 다룰 수 있게 됩니다.
