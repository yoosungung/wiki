# Parlant

AI 챗봇 개발의 큰 이슈는 일관되지 않은 LLM 동작이죠. 그런데 #금융, #의료, #법률 등 규제 업계에서 실제 사용중인 (그만큼의 정확성과 일관성을 보장하는) #오픈소스 AI챗봇 프레임워크가 있다는 사실… 알고 계셨나요? 사실 어떻게 보면 프롬프팅으로 규제를 하고, 시나리오 케이스를 나누어 정확히 의도한 대로만 움직이게 만든다는 누구나 떠올려 봤을 법한 아이디어지만, 바로 그 아이디어를 누군가 코드로 만들어 줬으니 한번쯤은 살펴볼 가치가 충분히 있어 보입니다. 아무튼, #Parlant 오픈소스는 자연어 명령으로 "LLM이 정확히 내가 원하는 대로만 동작하게" 만들어주는 오픈소스 프레임워크라고 합니다. React 컴포넌트와 REST API 연동을 통해 기존 애플리케이션과 완벽 통합도 가능하답니다. React 컴포넌트로 바로 웹앱에 붙일 수도 있어요. - 주요 기능 요약 ✅ 자연어 규칙 정의: "고객이 화나면 상담사에게 연결해줘" 이런 식으로 간단하게 ✅ 똑똑한 맥락 파악: 대화 흐름 보고 지금 어떤 규칙 적용할지 알아서 판단 ✅ 외부 도구 연결: 장바구니 추가, DB 조회 등 실제 업무와 바로 연동 ✅ 출력 내용 제어: LLM이 이상한 소리 못하게 템플릿으로 답변 형식 고정 ✅ 프로덕션 검증됨: 금융, 의료, 법률 등 까다로운 업계에서 실제 사용 중 저도 이번 명절에 가지고 놀아봐야겠습니다.ㅎㅎ
