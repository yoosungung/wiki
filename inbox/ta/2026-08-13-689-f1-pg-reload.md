# PG f1 pit_stops/retirements empty → reload notes

- Confirmed live `spider2db.f1.pit_stops`/`retirements`/`results` were 0 while SQLite `spider2-localdb/f1/f1.sqlite` had 10990/11568/26519.
- `spider2-localdb` (1.6G) lives on **nl2sql agent PVC** (`cursor-agent-nl2sql-0` → `spider2-eval/.tmp-spider2/...`), not on ta ephemeral `/tmp/tenant-repos` shallow checkout.
- `uv run spider2-load-pg --only-schemas f1` can fail on `liveries`: SQLite allows NULL in PK `end_year` (10 rows); PG PRIMARY KEY implies NOT NULL. Workaround: copy sqlite → `UPDATE liveries SET end_year=9999 WHERE end_year IS NULL` → load (or targeted table reload).
