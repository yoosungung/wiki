# EH smoke soft-skip when xvfb-run missing

- Headless Linux + empty DISPLAY: `run-vscode-test.cjs` used to `spawnSync('xvfb-run')` → ENOENT failed `npm --prefix extension run ci` after unit pass (`test.coupled`).
- Fix: `extension/scripts/xvfbGuard.cjs` — PATH probe + `softSkipDecision`; missing xvfb-run → stderr message + exit 0 before download/spawn. Unit (`npm test`) stays always-on floor.
- Documented in `.factory/quality.yaml` header/e2e/clean_code comments; `extension/DESIGN.md` Commands note soft-skip.
- Soft-skip reduces gate noise; EH coverage still requires xvfb (or DISPLAY) on runners that enforce Host smoke.
